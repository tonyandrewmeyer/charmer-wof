# gotify-k8s

A new Kubernetes charm, written with the `ops` library. Nothing has been
written yet.

## Commands

- Unit tests: `uv run pytest tests/unit`
- Lint: `uv run ruff check` and `uv run ruff format --check`
- Charm linter: `uvx charmlint .`

`charmcraft`, Juju and Kubernetes are not available here: test with
`ops.testing` (Scenario).
